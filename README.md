## Sobre este repositório

Este repositório reúne projetos e atividades desenvolvidos durante a trilha de **IA & Dados da Geração Caldeira 2026**.

O objetivo é registrar minha evolução técnica, aplicar os conhecimentos adquiridos e desenvolver soluções que conectem tecnologia, análise de dados e problemas reais.

## Projeto em destaque — Desafio GC 2026

### Análise e padronização de descrições de serviços

No contexto do desafio relacionado à Gerdau, o trabalho de IA & Dados parte de um problema de qualidade de dados: descrições de serviços cadastradas manualmente podem apresentar duplicidades, variações de escrita e inconsistências que dificultam a organização e a análise das informações.

**Objetivo:** explorar técnicas de tratamento e comparação de textos para identificar descrições potencialmente semelhantes e apoiar a revisão e a padronização dos cadastros.

### Etapas exploradas

- Análise exploratória da base de dados anonimizada.
- Identificação de descrições repetidas.
- Normalização textual, incluindo tratamento de espaços, letras maiúsculas e acentos.
- Comparação de similaridade entre descrições.
- Análise de diferenças em números, medidas e unidades para reduzir possíveis associações incorretas.
- Organização de candidatos para análise e revisão.

## Atividades acadêmicas

Além do desafio principal, este repositório reúne exercícios e projetos desenvolvidos ao longo da formação.

### Casa de Sucos API — Aula 14

API desenvolvida com Python e FastAPI para consultar informações nutricionais de frutas e cadastrar sucos.

**Funcionalidades:**
- Consulta de frutas por meio da API Fruityvice.
- Cadastro e listagem de sucos.
- Cálculo dos totais de calorias e açúcar.
- Atualização das frutas de um suco.
- Tratamento de erros de consulta.

**Tecnologias:** Python, FastAPI, Uvicorn, Requests e integração com API externa.

[**Acessar o projeto Casa de Sucos API**](Aula_14/)

> Os sucos são armazenados em memória nesta versão, portanto os registros são perdidos quando a aplicação é reiniciada.
